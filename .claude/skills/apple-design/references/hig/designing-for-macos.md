# Designing for macOS — Apple Human Interface Guidelines

## Core Device Characteristics

macOS users engage in in-depth productivity tasks, view media or content, and play games, often using several apps at once.

**Display and Workspace**: Macs feature large, high-resolution displays with the ability to connect additional screens for extended workspace.

**Usage Context**: Users typically work at stationary locations, with viewing distances from about 1 to 3 feet.

**Input Methods**: Keyboard, trackpad/mouse, game controllers, Voice Control, Siri.

**Work Patterns**: Sessions range from brief tasks to several hours of deep concentration, with users regularly toggling between multiple open applications.

## Design Priorities

**Maximize large displays** — present more content in fewer nested levels without overwhelming users. Sidebars, inspector panels, and split views are native macOS patterns for using screen real estate well.

**Flexible window management** — users can resize, hide, show, and move windows. Layouts must adapt gracefully across window sizes, including compact states when windows are snapped or tiled.

**Menu bar integration** — provide easy access to all commands through the menu bar. macOS users expect every significant action to be discoverable via the menu bar, even if it's also accessible via toolbar or context menu.

**Keyboard efficiency** — support keyboard shortcuts for all common actions. Power users rely on the keyboard; mouse-only interfaces feel sluggish on macOS.

**Customization** — allow users to customize toolbars, window layouts, and visual preferences where appropriate. macOS users expect to make the environment their own.

## Interaction Patterns

- Right-click (secondary click) context menus for item-level actions
- Drag and drop between apps
- Toolbar for frequently used actions; inspector sidebar for contextual properties
- Preferences/Settings window for app configuration
- Sheet dialogs (attached to window) rather than free-floating dialogs where possible
- Document-based apps: use standard Open/Save/Auto-save patterns

## Content Density

macOS can display more information than mobile platforms. Use this to reduce navigation depth — information that requires three taps on iOS may be visible directly on macOS. Avoid excessively large controls or excessive white space that wastes screen real estate.
